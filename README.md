# Evercode Fast Track — backend

Backend-основа REST API для отслеживания криптовалют. Проект рассчитан на Node.js 24, Express и встроенный `node:sqlite`; данные хранятся в файле SQLite.

## Реализованный срез

- защищённый `GET /api/tracked-cryptocurrencies`, возвращающий пустой список из SQLite;
- Bearer-аутентификация и безопасный формат ошибок;
- отдельное создание приложения и запуск HTTP-процесса;
- схема SQLite для криптовалют, записей отслеживания и истории цен;
- проверка конфигурации окружения до запуска;
- основа Docker с постоянным томом для SQLite.

CRUD, обращения к CoinMarketCap, чтение цен и истории, Swagger и фоновые задачи пока не реализованы. Настоящий API-ключ CoinMarketCap для этого среза не требуется; тесты не обращаются к CoinMarketCap.

## Требования и локальный запуск

Нужен Node.js 24. Установите зависимости, создайте локальный файл окружения и запустите приложение:

```sh
cp .env.example .env
# Замените значения API_TOKEN и COINMARKETCAP_API_KEY в .env
mise exec node@24 -- npm ci
mise exec node@24 -- npm start
```

`API_TOKEN` защищает собственный API, а `COINMARKETCAP_API_KEY` предназначен только для будущих обращений к поставщику. Это разные секреты. Не добавляйте `.env` в Git. Для текущего среза ключ CoinMarketCap не используется.

Путь к файлу SQLite задаёт `DATABASE_PATH`. По умолчанию из примера это `./data/evercode.sqlite`; каталог создаётся автоматически. В памяти процесса данные не хранятся.

## Настройки окружения

| Переменная | Назначение | Значение примера |
| --- | --- | --- |
| `API_TOKEN` | Обязательный Bearer-токен собственного API | замените случайным секретом |
| `COINMARKETCAP_API_KEY` | Отдельный ключ внешнего API | замените ключом поставщика при интеграции |
| `PORT` | Порт HTTP-сервера, от 1 до 65535 | `3000` |
| `DATABASE_PATH` | Путь к файлу SQLite на диске | `./data/evercode.sqlite` |
| `PRICE_CURRENCY` | Валюта сервиса; пока поддерживается только USD | `USD` |
| `CMC_TIMEOUT_MS` | Таймаут будущих HTTP-запросов к поставщику | `10000` |
| `SYNC_INTERVAL_MS` | Настройка будущей фоновой синхронизации | `60000` |

При запуске сервис проверяет обязательные значения и числовые диапазоны. Секреты не выводятся в HTTP-ответах или журналах.

## API

Единственный опубликованный маршрут этого среза требует заголовок `Authorization: Bearer <API_TOKEN>`:

```sh
curl http://localhost:3000/api/tracked-cryptocurrencies \
  -H 'Authorization: Bearer replace-with-a-long-random-service-token'
```

Успешный ответ для новой базы:

```json
[]
```

Отсутствующий, неверный или неправильно оформленный токен возвращает `401` с безопасным машинным кодом `UNAUTHORIZED`. Неизвестный маршрут возвращает `404` в том же формате ошибок.

## Проверки

```sh
mise exec node@24 -- npm run build
mise exec node@24 -- npm test
```

Jest запускает собранный TypeScript-код без трансформера. HTTP-тесты выполняются через Supertest и используют отдельные временные файлы SQLite на диске.

## Docker Compose

Скопируйте пример окружения, задайте собственные значения, затем соберите и запустите контейнер:

```sh
cp .env.example .env
# Отредактируйте .env
mise exec node@24 -- docker compose up --build
```

Compose хранит базу в именованном томе `sqlite-data`. Файл окружения исключён из Docker-контекста и Git. Команда Compose требует доступный Docker daemon.
