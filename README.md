# Evercode Fast Track — backend

Тестовое задание: REST API для отслеживания криптовалют, получения цен из CoinMarketCap и хранения истории.

## Состояние проекта

Создан только каркас репозитория. Код приложения, Docker-конфигурация, тесты и OpenAPI-документация будут добавляться по мере выполнения плана ниже. Запустить сервис пока нельзя.

Локальный файл `.env` создан пустым и исключён из Git. База данных также не должна попадать в репозиторий.

## Что должен делать сервис

- Защищать собственное API через `Authorization: Bearer <API_KEY>`.
- Позволять добавлять, просматривать, изменять и удалять отслеживаемые криптовалюты.
- Получать цены из официального CoinMarketCap API.
- Хранить текущие цены и историю в SQLite.
- Возвращать историю цен выбранной криптовалюты.
- Обновлять цены по расписанию и корректно завершать фоновые задачи при остановке.
- Обрабатывать таймауты, ошибки и недоступность CoinMarketCap.
- Предоставлять OpenAPI 3.0-документацию.

Под агрегацией здесь понимается сбор цен отслеживаемых криптовалют в одном сервисе. Расчёт средних цен и другой статистики пока не входит в план.

## Предварительный технический выбор

- Node.js 24, Express.js, TypeScript.
- SQLite: встроенный модуль `node:sqlite`, только raw SQL.
- axios для запросов к CoinMarketCap.
- Jest и Supertest для тестов.
- Swagger / OpenAPI 3.0.
- Docker и Docker Compose для запуска.

Node.js 24 удовлетворяет требованию «18+» и позволяет работать с SQLite без стороннего драйвера. В Node.js 18 встроенного SQLite нет: если потребуется именно эта версия, понадобится согласовать библиотеку-драйвер. ORM не используется.

Средства разработки TypeScript и Jest, а также средство публикации Swagger-документации нужно уточнить при настройке зависимостей: условие «только указанные библиотеки» не перечисляет все вспомогательные пакеты.

- [ ] **4. Поднять минимальное API.** Разделить создание Express-приложения и запуск сервера. Добавить Bearer-аутентификацию, проверку входных данных и единый формат ошибок. Не передавать клиенту ключ CoinMarketCap.

## Предварительные маршруты

Имена маршрутов можно уточнить перед реализацией.

| Метод | Путь | Назначение |
| --- | --- | --- |
| POST | `/api/cryptocurrencies` | Добавить криптовалюту |
| GET | `/api/cryptocurrencies` | Получить список |
| GET | `/api/cryptocurrencies/:id` | Получить одну запись |
| PATCH | `/api/cryptocurrencies/:id` | Изменить запись |
| DELETE | `/api/cryptocurrencies/:id` | Удалить запись |
| GET | `/api/cryptocurrencies/:id/price` | Получить последнюю сохранённую цену |
| GET | `/api/cryptocurrencies/:id/history` | Получить историю цен |

Все маршруты собственного REST API требуют Bearer-токен. Цены возвращаются в одной настроенной валюте, например USD. Пока это проект API, а не реализованные маршруты.
