# Быстрый запуск

Все команды выполняйте из корня склонированного репозитория.

## 1. Настройте ключи

```sh
cp .env.example .env
```

Откройте `.env` и замените два значения:

- `API_TOKEN` — ваш длинный случайный токен для доступа к этому сервису.
- `COINMARKETCAP_API_KEY` — ваш API Key CoinMarketCap.

Ключи должны отличаться. Остальные настройки можно оставить как в примере. Приложение создаст SQLite-базу автоматически.

Для запуска подходит бесплатный тариф CoinMarketCap Basic.[^basic]

[^basic]: В `.env.example` приведены лимиты Basic: 10 000 кредитов в месяц и 30 запросов в минуту. Блок учёта квоты закомментирован; при запуске по этой инструкции ограничения применяет CoinMarketCap.

## 2. Запустите сервис

Выберите один способ запуска.

### Через Docker

Нужны запущенный Docker и Docker Compose. Устанавливать Node.js локально не требуется: контейнер использует Node 18.

```sh
docker compose --env-file .env up --build -d
docker compose --env-file .env logs -f api
```

Дождитесь сообщения `HTTP server listening on port 3000`. Чтобы выйти из просмотра логов, нажмите `Ctrl+C`: сервис продолжит работать.

### Локально

Нужны Node.js 18+ и npm. Команды ниже рассчитаны на Bash или Zsh.

```sh
npm ci
set -a
. ./.env
set +a
npm start
```

Приложение читает переменные окружения, поэтому `.env` нужно загрузить в оболочку перед запуском. `npm start` собирает TypeScript и запускает сервис. Дождитесь сообщения `HTTP server listening on port 3000`.

Если SQLite-драйвер не устанавливается в вашем локальном окружении, используйте Docker.

## 3. Проверьте API

При стандартном `PORT=3000` откройте:

- Swagger UI: [http://localhost:3000/docs](http://localhost:3000/docs).
- OpenAPI 3.0: [http://localhost:3000/openapi.json](http://localhost:3000/openapi.json).

В Swagger нажмите **Authorize** и введите значение `API_TOKEN` без префикса `Bearer`. Затем выполните `POST /api/tracked-cryptocurrencies` с телом:

```json
{"cmcId": 1}
```

Для новой записи ожидается `201`: сервис добавит Bitcoin и сохранит первую цену. Затем вызовите `GET /api/prices`, чтобы получить актуальные цены. Эти операции обращаются к CoinMarketCap и требуют действующего ключа и доступной квоты.

Описание всех маршрутов, параметров и ошибок находится в [README: API](README.md#api).

## Тесты

При установленном Node.js 18+ выполните:

```sh
npm ci
npm test
```

Тесты используют локальный сервер вместо CoinMarketCap и временную SQLite-базу. Настоящие ключи и запущенный сервис не нужны.

## Остановка

Для Docker:

```sh
docker compose --env-file .env down
```

Для локального запуска нажмите `Ctrl+C` в терминале сервиса.

Данные сохраняются: в Docker — в томе `sqlite-data`, локально — в `./data/evercode.sqlite`.
