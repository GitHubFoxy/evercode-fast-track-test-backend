# 0002. Поддержка Node начиная с 18.0.0 через `better-sqlite3`

Проект должен работать на Node.js 18.0.0 и последующих версиях, включая текущую Node 26. Встроенный `node:sqlite` заменён на `better-sqlite3`: SQL, схема SQLite и явные транзакции сохраняются, ORM не используется. По прямому указанию пользователя сторонний драйвер разрешён; решение заменяет ADR 0001.

`better-sqlite3` 11.10.0 поддерживает Node 18, но не собирается на Node 26 из-за изменений V8. Версия 13.0.3 требует Node ≥22. Поэтому обе версии закреплены как optional dependencies: 11.10.0 под именем `better-sqlite3-node18`, 13.0.3 под обычным именем. Приложение выбирает вторую только для Node ≥22 с Node-API ≥10, в остальных случаях — первую. Ранние версии Node 22 используют Node-API 9 и тоже требуют первой версии драйвера. npm пропускает несовместимые optional packages; выбранный драйвер обязателен при запуске. `allowScripts` разрешает установку нативного драйвера и в npm 12. При отсутствии готового бинарника нужна нативная сборка; npm 9, поставляемый с Node 19, требует Python ≤3.11.

`engines.node` задаёт `>=18.0.0`, типы Node относятся к версии 18, Jest 29.7.0 поддерживает нижнюю границу. Приложение читает только переменные окружения: локальный `.env` экспортирует оболочка перед запуском, Docker Compose передаёт настройки контейнеру. Дополнительная библиотека для чтения `.env` не требуется. HTTP-соединения закрываются через учёт сокетов: `Server.closeAllConnections` отсутствует в Node 18.0.0. Обе стадии Docker используют `node:18-bookworm-slim`; нативные зависимости устанавливаются в стадии сборки и копируются в образ запуска без компилятора.
