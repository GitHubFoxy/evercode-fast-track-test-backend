# 0001. Встроенный `node:sqlite` вместо стороннего драйвера

**Статус:** принято

## Контекст

Задание требует Node.js 18+, SQLite без ORM и запрещает библиотеки сверх перечисленных. Node 18 не содержит встроенного SQLite, а сторонние драйверы (`sqlite3`, `better-sqlite3`) в список не входят и требуют нативной сборки.

## Решение

Использовать встроенный `node:sqlite` (Node ≥ 22.5) и raw SQL. Минимальная версия закреплена в `package.json` (`engines.node >= 22.5.0`), Docker-образ основан на Node 24.

## Последствия

- Нет ORM и нет дополнительных зависимостей для БД, нет нативной сборки.
- Node 18–21 не поддерживаются: это осознанное отступление от «Node 18+».
- Модуль `node:sqlite` помечен как экспериментальный, поэтому при запуске Node может печатать предупреждение.
