# Метки задач

| Роль | Метка | Значение |
| --- | --- | --- |
| needs-triage | needs-triage | Требует разбора |
| needs-info | needs-info | Требует уточнений |
| ready-for-agent | ready-for-agent | Готова к выполнению агентом |
| ready-for-human | ready-for-human | Требует выполнения человеком |
| wontfix | wontfix | Не планируется |

Скиллы используют метку, соответствующую роли.
Для изменения словаря менять правую колонку с меткой, сохраняя каноническую роль.
