# Документация предметной области

Единый контекст: `GLOSSARY.md` в корне, решения — в `docs/adr/`.

Перед изучением проекта читать словарь и относящиеся к задаче архитектурные решения.

Если файлов нет, продолжать без предупреждений. Создавать их только после согласования конкретных терминов или решений, не создавать пустые заготовки.

Использовать термины из словаря последовательно, в том числе в задачах, предложениях и тестах. Не помещать в словарь детали реализации. Если нужного понятия нет, проверить, действительно ли оно нужно, и предложить его уточнение.

Противоречия существующим решениям обозначать явно, а не молча заменять принятое решение.
